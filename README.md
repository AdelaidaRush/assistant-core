# Рабочая модель ассистента

Свод правил, протоколов и разборов, по которым работает ассистент. Это не программа и не набор
весов, а память: markdown-файлы, которые модель читает перед работой и которые определяют, как
она думает, что проверяет и что имеет право сдать.

## Как этим пользоваться

**В браузерном Claude Code.** Выбрать этот репозиторий как рабочий. Файл `CLAUDE.md` в корне
подхватывается автоматически, память лежит в `brain/`. Дальше достаточно поставить задачу:
ассистент сам открывает индекс, находит нужные правила и работает по ним.

**В Obsidian.** Открыть папку `brain` как vault. Связи в двойных квадратных скобках станут
кликабельными, появится граф.

**В локальном Claude Code.** Клонировать репозиторий и работать в нём как в обычном проекте.

## Что внутри

| Папка | Что там |
|---|---|
| `brain/_INDEX.md` | маршрутизатор: одна строка на тему, точка входа в любую сессию |
| `brain/System/` | протоколы работы, гейты, правила текста, разборы измерений |
| `brain/Playbooks/` | пайплайны по типам работы: код, тексты, кампании, баннеры, видео |
| `brain/Preferences/` | вкус заказчика: как общаться и какой результат считается хорошим |
| `brain/Templates/` | каркасы заметок и запуска нового проекта |

## Порядок чтения

Сессия не читает всю память целиком, это дорого и вредно. Она читает `brain/_INDEX.md`, потом
только те заметки, чья строка совпала с задачей. Правило записано в `brain/System/token-rules.md`.

## Чего здесь нет и почему

Это очищенная версия. Из неё убраны данные проектов, имена, почты, аккаунты, доступы и пути к
файлам на конкретной машине. Осталась только модель работы, применимая к любой задаче.

Часть заметок ссылается на локальные инструменты, которых в облаке нет: свой ИИ-детектор текста,
каталог скиллов, локальные библиотеки анимации. В тексте они помечены угловыми скобками, например
`<локальный ИИ-детектор>`. Правило при этом остаётся в силе, меняется только способ проверки:
вместо локального скрипта берётся любой доступный инструмент того же назначения.

## Как это пополняется

Новое знание записывается атомарной заметкой по формату `brain/System/memory-protocol.md`, и на неё
добавляется строка в `brain/_INDEX.md`. Заметка без строки в индексе не будет найдена, а значит
не существует для работы.
