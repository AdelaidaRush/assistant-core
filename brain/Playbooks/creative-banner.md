# 🖼 Playbook — баннер / креатив

**Контекст перед стартом:** ⭐ (ГЛАВНОЕ правило — продать тему: на скрине магазин+оформление+модули, копи «продашь больше»), (ДНК), (вкус владельца), (чем генерить фон),.

## Этапы
1. **Бриф.** Платформа/формат (по умолч. 1080×1350), одно сообщение, цель. Свериться с реальными материалами проекта по ссылкам.
2. **Концепты — 2–3 РАЗНЫХ** (разные фоны/композиции/метафоры, не один объект в разных цветах). Цвет фона можно отходить от тёмного+жёлтого. → **ГЕЙТ: согласовать с владельцем.**
3. **Арт-дирекшн** (ведущий `frontend-design`, справочно `ui-ux-pro-max`): сетка, типографика (Anton/Archivo Black UPPERCASE display + чистый сан body), акцент `#E3FF00`.
4. **Продакшн:**
 - Герой/фон — **AI** через (auto: fal если есть баланс → локальный FLUX → Pollinations). Промпт под бренд: премиум, чёрный, кислотный жёлтый свечение.
 - Текст и лейаут — **кодом** (`utd-banner-engine`, HTML→PNG, авто-fit, overflow-guard). Текст = живой HTML, не растр.
5. **QA-петля (обязательна):** рендер PNG → `ui-visual-validator` смотрит глазами → найти 1 слабое место (иерархия/контраст/ритм/негативное пространство/слоп) → исправить → повтор до планки. `stop-slop` на текст.
6. **Деливери:** нужные форматы (Stories 1080×1920, квадрат 1080×1080, OG 1200×630).
7. **Фидбэк:** правка владельца → /.

## Планка качества (не сдавать ниже)
Чёткий контраст текст/фон · max 2 шрифта · один фокус · CTA заметен · без AI-слопа · единый размер шрифта в группах · видна насмотренность, а не шаблон.

## Эталоны стиля
Реальные креативы прежнего проекта — (`<локальный путь>`). Сверяться перед генерацией.
