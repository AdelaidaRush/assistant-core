# Playbooks — как делается работа каждого типа

- [[coding]] — код, фича, баг, автоматизация: понять → план → сделать → проверить запуском
- [[copywriting]] — любой текст: черновик → правка ритма → проверка на машинность
- [[marketing-campaign]] — кампания и контент-план: цель → аудитория → угол → каналы
- [[creative-banner]] — баннеры и креативы: бриф → два-три концепта → сборка → рендер и просмотр
- [[video-reel]] — рилсы и видео: честный выбор движка, сценарий, гейт на согласование
- [[sales-conversion-levers]] — 26 правил для конверсионных текстов
- [[mechanism-observability]] — какие три поля делают механизм наблюдаемым

Общий закон для всех: ни один пайплайн не заканчивается на сборке. Заканчивается он на просмотре
результата глазами и на исправлении одного найденного слабого места.
