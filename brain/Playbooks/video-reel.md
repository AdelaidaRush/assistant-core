# 🎬 Playbook — рилс / видео

**Контекст перед стартом:** `reel-script-writer`, [[video-prefs]], ·.

## Честный выбор движка (по бюджету)
- 🥇 **LTX-2.5 через <локальный файл> — движок по умолчанию** (решение владельца 20.08.2026).
 Видео и синхронный звук одним проходом, нативный мультишот, до 4K и до 20 с.
 Рилс 1080×1920 на 8 с = $1.04 на `ltx-2-5-fast`; черновики гонять на `ltx-2-3-fast` ($0.03/с в 720p).
 **Нужен ключ LTX**; без `--yes` скрипт ничего не отправляет. См..
- 🟢 **fal с балансом / Higgsfield** → запасной путь, если LTX не подходит по стилю. См..
- 🟡 **Бесплатно (рабочий путь):** реальный сток-футаж 4K (Pexels/Pixabay API) + моушн и кинетик-типографика кодом (Remotion как монтажный слой) + AI-картинки-инсерты (локальный FLUX/Pollinations) + трендовый звук.
- 🔴 **Не выдавать чистый Remotion за современный рилс** — это корпоративная заставка. См..

## Этапы
1. **Бриф:** платформа (IG Reels 1080×1920, ≤30–45с), хук, одно сообщение, оффер.
2. **Сценарий** (`reel-script-writer` + `stop-slop`): хук в первые 1–2с, структура «проблема → наша тема → доказательство (скорость/конверсия) → CTA». → **ГЕЙТ: согласовать.**
3. **Раскадровка:** сцены, что — сток, что — AI-кадр, где текст-оверлеи.
4. **Сборка:** сцены генерим LTX (`t2v` для планов с нуля, `i2v` для оживления утверждённого кадра) → монтаж (ffmpeg/Remotion) → кинетик-текст в бренд-типографике → музыка → ритм по бите. Звук LTX даёт сам, отдельный слой нужен только под трек и голос.
5. **QA глазами:** смотреть целиком на телефоне-формате → хук цепляет? ритм не провисает? текст читаем? → правка → повтор.
6. **Деливери + фидбэк** в [[video-prefs]]/.
