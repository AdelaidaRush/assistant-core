# 💻 Playbook — код / фича / баг / автоматизация

**Контекст перед стартом:** язык-скилл (`python-pro` и т.п.), релевантная тех-заметка.

## Этапы
1. **Понять цель и контекст.** Прочитать существующий код прежде чем менять. Не плодить дубль — искать, что уже есть в montage.
2. **План** (на нетривиальном — `make-plan`): шаги, файлы, риски.
3. **Реализация:** код в стиле окружающего кода. Один ведущий язык-скилл, без хора.
4. **Проверка (`verification-before-completion`):** запустить/протестировать реально. Не говорить «готово» без проверки. Если упало — сказать прямо с выводом.
5. **Безопасность:** auth/payment/данные/секреты → отдельная проверка. Секреты — только из `<локальный каталог>`, не печатать в чат, не коммитить.
6. **Фидбэк** (повторяющиеся грабли → правило).

## Принципы
- Коммит/пуш — только когда владелец просит.
- Хард-необратимое (удаление/перезапись) — сначала посмотреть на цель, подтвердить.
- n8n — следовать рабочему состоянию из (Google Ads v21, ручная привязка cred, именование).
