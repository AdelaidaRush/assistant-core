# Шеринг с сайта: что платформы реально позволяют

Проверено при написании ТЗ на кнопку «Поделиться» 27.08.2026. Полный документ и рабочий код —
каталог проекта с кнопкой «Поделиться».

## Три факта, которые определяют любую задачу про шеринг

**Директ в Instagram, LinkedIn и X с сайта достаётся ровно одним способом** — через системное меню
телефона (`navigator.share`). Публичных веб-адресов для личных сообщений у этих трёх нет. Прямой
выбор друга по ссылке умеют только Telegram (`t.me/share/url`) и WhatsApp (`wa.me/?text=`).

**У Instagram нет веб-адреса для шаринга вообще.** Ни для поста, ни для директа, ни для сторис.
Схема `instagram-stories://share` работает только из нативного приложения с Facebook App ID и
передаёт картинку через системный буфер обмена, куда Safari писать не может. Из браузера путь
один: отдать готовую картинку 1080×1920 в приложение, дальше человек публикует сам.

**В `navigator.share` для сторис нельзя передавать `files` и `url` вместе.** iOS считает набор
«ссылкой с вложением», и Instagram пропадает из списка приложений. Только файл.

## Ловушки, стоящие дня отладки

- `navigator.share` вызывается синхронно внутри обработчика клика. Любой `await` перед ним теряет
 жест, браузер отказывает, и это выглядит как «кнопка иногда не работает».
- Отказ человека приходит как `AbortError`. Это не сбой, показывать ошибку нельзя.
- Без мета-тегов Open Graph ссылка уходит голой строкой. LinkedIn игнорирует параметры `title` и
 `summary` с 2021 года и берёт карточку только из тегов страницы.
- Firefox на десктопе системного меню не имеет вовсе — своё окно выбора сети обязательно.
- Безопасные поля сторис: 250 px сверху и 300 px снизу закрыты интерфейсом Instagram.
