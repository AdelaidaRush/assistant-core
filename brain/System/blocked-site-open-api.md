# Закрытый антиботом госсайт — сначала его же API, потом вывод о недоступности

## Замер

10.08.2026, документ Federal Register **2026-10375**.

| Канал | Результат |
|---|---|
| Прямой запрос страницы документа | **302** на `unblock.federalregister.gov`, то есть антибот |
| `https://www.federalregister.gov/api/v1/documents/2026-10375.json` | **отдан с первой попытки**, поля `title`, `abstract`, `action`, `dates`, `comments_close_on` |

## Правило

Порядок попыток перед любым выводом о недоступности источника:

1. прямой запрос страницы;
2. **машинный интерфейс на том же хосте**: `/api/`, `/api/v1/`, суффикс `.json`, поддомен `data.`;
3. Jina Reader;
4. и только теперь вывод, и то по правилу
 — две неудачи на двух разных объектах,
 с датой перепроверки.

## Почему шаг 2 стоит вставить именно вторым

Машинный интерфейс государственного реестра существует не по доброй воле площадки, а по требованию
об открытых данных, поэтому антибот на него обычно не ставят. Он дешевле Jina Reader (один запрос
вместо прокси) и точнее его: отдаёт поля вместо вёрстки, то есть дата, срок комментариев и тип
действия приходят как значения, а не как текст, который надо вычитывать глазами.

## Известные адреса, где это работает или обязано работать

| Домен | Прямой запрос | Машинный интерфейс |
|---|---|---|
| `federalregister.gov` | 302 на `unblock.` | `/api/v1/documents/<номер>.json` — **проверено 10.08.2026** |
| `sec.gov` | 403 (проверено 07.08 и 09.08) | `data.sec.gov` — **не проверено**, до 10.09.2026 |
| `regulations.gov` | не проверялся | `api.regulations.gov` (нужен ключ) — не проверено |
| `apra.gov.au`, `occ.gov` | читаются напрямую или через Jina | машинного интерфейса не искали |

## Граница честно

API Federal Register отдаёт **аннотацию** документа, а не его тело. Вывод про паузу по заявкам
Tier 3 сделан из аннотации, а перечень ограничений платёжного счёта и дата окончания паузы взяты из
разборов юридических фирм и помечены непроверенным. Чтение тела документа остаётся открытым шагом.

Родственно:, отдельное предложение, класс A62.
