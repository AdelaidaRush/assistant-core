# 🎬 Движение на сайтах: GSAP + anime.js

владелец 30 июля 2026: поставить GSAP для анимаций на прокручивание и anime.js для векторной анимации, использовать при создании будущих сайтов, чтобы они выглядели привлекательнее.

**Why:** сайты, собранные на одних CSS-переходах, читаются как шаблон. Разница между «сделано» и «дорого» почти всегда в движении: как появляется секция при скролле, как собирается заголовок, как оживает цифра. Это то же, что петля критики для баннеров, только для страниц.

**How to apply:** на каждом сайте, лендинге, промо-странице и дашборде брать скилл `web-animation-stack` вместе с `frontend-design`. Разделение жёсткое:

| Задача | Инструмент |
|---|---|
| Появление секций при скролле, пиннинг, параллакс, горизонтальный скролл, плавный скролл | GSAP + ScrollTrigger / ScrollSmoother |
| Заголовок собирается по буквам или словам | GSAP + SplitText |
| Перестроение сетки, карточка → модалка | GSAP + Flip |
| SVG-линии, морфинг фигур, иконки, логотип | anime.js (или GSAP DrawSVG/MorphSVG, если сцена уже на GSAP) |
| Счётчики, стаггер по сетке, микровзаимодействия | anime.js |
| Один hover-переход | обычный CSS, библиотека не нужна |

Не тащить обе библиотеки туда, где хватает одной.

## Где лежит

- Библиотеки: `<локальный каталог библиотек анимации>` — **gsap 3.15.0** (dist со всеми плагинами: ScrollTrigger, ScrollSmoother, SplitText, Flip, MorphSVG, DrawSVG, Observer, MotionPath, Draggable) и **animejs 4.5.0**.
- Скилл: `<каталог скиллов>` + симлинк в `<локальный каталог>`. Внутри `SKILL.md` (правила и паттерны), `lib/` (симлинк на библиотеки), `templates/starter.html` (рабочий пример обеих библиотек).
- Офлайн-подключение важно для рендера через Playwright, где CDN может не подняться.

## Проверено рендером (2026-07-30)

Прогнал `templates/starter.html` через Playwright: GSAP 3.15.0 поднялся, SplitText разбил заголовок на 8 слов, зарегистрировалось 2 ScrollTrigger'а, счётчик anime.js досчитал до +312%, SVG-линия отрисовалась, **ноль ошибок в консоли**. API anime.js v4 подтверждён живьём: `anime.animate`, `anime.svg.createDrawable`, `anime.utils.round`.

## Правила качества

1. Движение служит иерархии. Двигается то, на что должен упасть взгляд. Двигается всё — не двигается ничего.
2. Длительность 0.3–0.8 с, ease `power2.out` / `power3.out`. `linear` только для бесконечных лент.
3. Анимировать только `transform` и `opacity`. `width`/`top`/`margin` роняют кадры.
4. Ничего важного не прятать за анимацией: текст и цифры читаются, даже если скрипт не выполнился.
5. `prefers-reduced-motion` обязателен.
6. Проверять глазами: отрендерить, прокрутить, посмотреть на 2-3 позициях скролла, найти одно слабое место, починить.
7. Мобильный отдельно — ScrollTrigger на 375×812 срабатывает раньше.
