# Исполненный код бьёт сформулированный

## Правило

**Код, попавший в ответ, исполняется до сдачи — хотя бы на синтетическом входе.** Не «выглядит
правильным», не «проверен чтением», а запущен, с кодом возврата и напечатанным результатом. Там, где
исполнение уже есть, силы на изощрённый промпт не тратятся: оси взаимозаменяемы.

## Чем измерено

NBER Working Paper **35588**, «AI Agents and Prompt Engineering in Econometric Coding» (Galiani, López,
Sosa, август 2026, https://www.nber.org/papers/w35588). Три оси эксперимента: статистический пакет
(Stata, R, Python), техника промпта (zero-shot против few-shot), уровень агентности (от чат-бота до
автономного агента). Модели — Claude Sonnet 4.6, GPT-5.4, Codex.

| Что мерили | Величина |
|---|---|
| Доля решённых задач, чат-бот | **74%** |
| Доля решённых задач, ограниченный агент | **96%** |
| Цена разницы | около **8 центов** за дополнительный прогон |
| Влияние few-shot | улучшает чат-бота **намного сильнее**, чем агента |
| Влияние выбора пакета (Stata/R/Python) | крупное у чат-бота, у агента почти исчезает |

Плюс 22 процентных пункта за центы — и это на задачах, где правильность проверяема.

## Три следствия, которые меняют работу

1. **Спор об инструменте имеет смысл только там, где код не исполняется.** Если исполняется, разница
 между пакетами почти исчезает, и время, потраченное на выбор, потрачено зря.
2. **Few-shot и исполнение — замены, а не дополнения.** Наращивать примеры в промпте поверх
 работающей петли исполнения смысла мало; это трата на ось, которая уже закрыта другой осью.
3. **Дисциплина проверок получила цену.** Правило «не показывать то, чего не видел работающим»
 держалось на приказе от 11.08; теперь у него есть число, и разговор о том, стоит ли лишний прогон,
 закрыт: стоит 8 центов, даёт 22 пункта.

## Где у нас код НЕ исполняется, проверено 14.08.2026

- SQL и pandas-разборы в аналитических ответах — уходят текстом, без прогона.
- Сборщики баннеров и рендер-скрипты — петля «отрендерил и посмотрел» есть для картинки, для самого
 скрипта нет.
- Сниппеты кода в статьях сети — публикуются как пример, не запускаются.

Где исполняется и это работает: очередь самомодификации. Пункт с прогнанными **обеими** половинами
проверки применяется машиной и не откатывается; до 11.08 восемь пунктов уходили с проверкой только
формата патча, и именно там появились два дефекта, въехавших вместе с починкой.
