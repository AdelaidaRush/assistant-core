# Детектор слеп на английском так же, как на украинском

**Измерено 24.08.2026** контрольным опытом, тем же приёмом, что раньше на украинском.

| Текст | Автор | Счёт |
|---|---|---|
| «The Best Code is No Code At All» | Джефф Этвуд, Coding Horror, 2007 | **41.3** |
| «Things You Should Never Do, Part I» | Джоэл Спольски, 2000 | **62.8** |
| Наша статья для Common Room | я | 42.5 |

Оба контрольных текста написаны людьми задолго до появления языковых моделей. Детектор
ставит им 41 и 63, то есть «спорно» и «машина». Значит на английском он меряет не
машинность, а что-то другое: скорее всего плотность и ровность академического слога.

**Правило.** Порог 30 применять только к русскоязычным текстам. Для английского и
украинского брать из отчёта только языконезависимые замечания:

- длинные тире (правило владельца, ноль в тексте),
- пронумерованные обещания вида «три вещи, которые»,
- связка «данные → анализ → совет» с рекомендацией в конце,
- повторяющиеся зачины абзацев.

Совет в конце убирается перестановкой: практику в середину, финал на неразрешённой детали.
Это структурная правка, и она единственная, которая реально двигает счёт. Переписывание
формулировок не двигает: на статье Common Room два прохода по ритму дали 46.6 → 41.1 → 42.5,
то есть шум.

**Перед выводом «текст не прошёл» на любом новом языке — сначала контрольный опыт**
на заведомо человеческом тексте того же языка и жанра. Без него меряется собственный шум.
