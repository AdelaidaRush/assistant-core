# ✍️ Copy preferences — вкус по текстам

Связано: (стандарт), [[copywriting]] (пайплайн).

## Нравится (do)
- Премиум-уровень, **как у профессионального копирайтера** — живой, с точкой зрения.
- Конкретика: цифры, факты, имена тем/фич (сверенные по ).
- Хук в первых 3 словах. Один смысл на сообщение. Ритм.
- Уверенный дорогой голос бренда: результат и механика, а не «решения и синергии».

## Не нравится (don't)
- Тексты «как у необученного Клода» — главная претензия владельца.
- Слоп: «в современном мире», «раскройте потенциал», «выведите на новый уровень», тройки прилагательных, вступление-вода.
- Эпитеты вместо фактов. Выдуманные названия/фичи тем.
- Обещания «буду писать как человек» без реального прогона по стандарту.

## Правило
Любой текст — обязательный прогон по + срез 20% слов перед сдачей.

> Пополняется при правках.
